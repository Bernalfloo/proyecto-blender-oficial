# 🚀 Cyber-Portfolio: The Alexis Josimar Experience

Welcome to the digital realm of **Alexis Josimar Bernal Flores**, a 20-year-old Software Engineering student who decided that boring, plain portfolios are a crime against the internet. 

This is not just a portfolio; it's a **minimalist, futuristic, neon-drenched cyber-experience** built from scratch. Buckle up! 🕶️✨

## 🌟 What's Inside this Bad Boy?

- **🧛‍♂️ Fallen Angel Aesthetics:** A dark, moody background featuring Satan the fallen angel (because why not?), with striking **neon red** accents that scream "I code in the dark."
- **🌞 Light/Dark Mode:** Too dark? Just flip the switch in the nav bar. We've got a fully functional Light Mode for those who prefer not to strain their retinas.
- **🎮 Interactive 3D Blender Model:** Yes, there's a fully functional 3D model embedded right into the site! You can spin it, zoom it, change its lighting with a custom slider, and even randomly mutate its colors like a mad scientist. 
- **🎵 The Bouncing Music Player:** A floating video player that bounces around the screen like an old-school DVD screensaver. Hover over it to catch it, and click anywhere to unmute the epic background track!
- **✨ Particle System:** A custom, native HTML5 Canvas particle system floating in the background. It even optimizes itself for mobile devices so your phone doesn't melt.
- **📱 100% Mobile Responsive:** Big buttons, stacking grids, and touch-friendly controls. It looks just as slick on a phone as it does on a 4K monitor.

## 🛠️ Tech Stack

No bloated frameworks here! Just pure, unadulterated web technologies:
- **HTML5** (Strict & Semantic)
- **CSS3** (Variables, Flexbox, Grid, Animations)
- **Vanilla JavaScript** (DOM manipulation, Canvas API, Event Listeners)
- **`<model-viewer>`** (Google's web component for 3D rendering)
- **Node.js** (A tiny custom local server because browsers hate loading 3D models directly from your hard drive).

## 🚀 How to Run It (Like a Boss)

Because modern browsers have strict security rules (CORS) that block 3D models (`.glb` files) from loading via simple `file:///` URLs, you need to run this through a local server. Don't worry, I built one for you!

1. Make sure you have [Node.js](https://nodejs.org/) installed.
2. Clone or download this repository.
3. Open your terminal in the project folder.
4. Run the magic command:
   ```bash
   node server.js
   ```
5. Open your browser and go to `http://localhost:8080`.
6. Enjoy the neon madness! 🔴🔥
